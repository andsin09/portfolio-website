01. Secure Cryptographic Password Vault (CLI)
Problem Statement

Local credential storage solutions frequently rely on insecure plain-text architectures or heavy dependencies. This system targets the requirement for an isolated, dependency-free command-line execution layer to manage encrypted local credentials securely.

Technical Stack

Python 3.x, Standard Cryptography Libraries (Fernet/Hashlib), JSON, Argparse.

Process & Reflection

Implementing secure PBKDF2 key-derivation processes within strict terminal-only limitations required careful exception handling for sensitive runtime memory. A primary hurdle surfaced when handling cross-platform terminal masking during credential entry (`getpass` module irregularities between Windows environments and POSIX shells). I resolved this behavior by embedding an environment-aware validation loop that dynamically checks standard I/O states before parsing runtime arguments.

Core Implementation Snippet 
def derive_key(passphrase: str, salt: bytes) -> bytes:
    """Generates an isolated cryptographic key leveraging SHA256 hashing."""
    kdf = PBKDF2HMAC(
        algorithm=hashes.SHA256(),
        length=32,
        salt=salt,
        iterations=100_000
    )
    return base64.urlsafe_b64encode(kdf.derive(passphrase.encode()))

02. Micro-Climate Greenhouse Controller (IoT)
Problem Statement

Agricultural environmental tracking systems often fail to scale effectively due to unstable edge loop cycles and inefficient data serialization protocols over wireless links.

Technical Stack

C++, Arduino IDE, ESP32 Microcontroller, DHT22 Sensor, I2C OLED Display, FreeRTOS.

[INSERT SCREENSHOT/DEMO VIDEO: Hardware Wiring & Sensor telemetry logs]
Process & Reflection

Developing for the ESP32 platform highlighted the critical importance of memory footprint optimization. Initial code variations experienced synchronous lag during Wi-Fi handshakes, which effectively halted sensor polling operations. To mitigate this block, I refactored the structural workflow using FreeRTOS tasks to isolate sensor collection and network telemetry onto separate processing cores.

Core Implementation Snippet 
void setupEnvironmentalTask() {
    xTaskCreatePinnedToCore(
        SensorReadLoop,    /* Task execution pointer */
        "SensorRead",      /* Debug identifier */
        4096,              /* Assigned stack allocation size */
        NULL,              /* Parameter assignments */
        1,                 /* Execution hierarchy priority */
        &SensorTaskHandle, /* Thread Reference */
        0                  /* Assigned Core Pointer */
    );
}

04. Automated Network Packet Analyzer Tool
Problem Statement

System Administrators require lightweight, easily deployable network metrics reporting tools that do not consume heavy desktop system resources during execution loops.

Technical Stack

Java (OpenJDK 17), Pcap4j Wrapper Library, Multi-threaded Logging Engine.

[INSERT SCREENSHOT/DEMO VIDEO: Terminal active packet inspection log stream]
Process & Reflection

Managing multi-threaded object references without causing thread deadlock was the primary challenge of this project. High-bandwidth environments drop interface instances if buffer parsing execution cycles lag. I successfully decoupled packet reception structures from disk-writing threads by leveraging an isolated, non-blocking `LinkedBlockingQueue` buffer pool.

Core Implementation Snippet 
public class PacketConsumer implements Runnable {
    private final LinkedBlockingQueue<Packet> bufferQueue;

    @Override
    public void run() {
        while (!Thread.currentThread().isInterrupted()) {
            try {
                Packet packet = bufferQueue.take();
                parseHeaderMetadata(packet);
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            }
        }
    }
}
