01. Congressional App Challenge Submission — MCST Bus Tracking App
Problem Statement

Our school's previous bus tracking solution was unreliable and difficult for students to use during dismissal. For the Congressional App Challenge, our team designed and developed a modern web application that allows students to quickly locate their assigned bus while providing administrators with a secure interface for managing bus assignments in real time.

Technical Stack

Next.js, React, TypeScript, Supabase, Tailwind CSS, Authentication & Session Management.

Process & Reflection

One of the primary challenges was creating a system that could be updated quickly by administrators while remaining simple for students to use during busy dismissal periods. We developed separate client and administrator interfaces, implemented secure authentication using hashed passwords and server-side session management, and connected the application to a Supabase backend for real-time bus assignment lookups. The project provided valuable experience working with full-stack web development, database integration, API routes, and collaborative software development practices.

Core Implementation Snippet 
export async function GET(request: NextRequest) {
const { searchParams } = new URL(request.url);
const bus = searchParams.get('bus');

const { data, error } = await supabase
.from('buses')
.select('id')
.eq('bus_name', bus)
.single();

if (error) {
return NextResponse.json(
{ bus, message: 'Bus has not arrived yet' },
{ status: 404 }
);
}

return NextResponse.json({
bus,
number: data.id
});
}

02. AI Lyrics Generator
Problem Statement

Large language models and generative AI systems have transformed how text can be created, but understanding the underlying technology requires building and training models from the ground up. This project uses natural language processing by creating an AI-powered lyrics generator capable of producing original song lyrics from user inputs.

Technical Stack

Python, PyTorch, LSTM Neural Networks, Natural Language Processing (NLP), Gradio,Git/GitHub.

Process & Reflection

Through this project, I trained a multi-layer LSTM model on lyric datasets and implemented temperature-based sampling to balance creativity with coherence during text generation. To further improve output quality, I combined neural network predictions with statistical language-model probabilities, resulting in more natural lyric sequences. The final product was deployed through a Gradio interface that allows users to generate custom lyrics and experiment with generation settings in real time.
